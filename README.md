# Pengauthor Bot
**The Pengauthor Discord Bot is a powerful utility that works behind the scenes at Club Penguin Armies.** It is built to make the work of Media Department members easier!** Pengauthor is a suite of various tools that simplify journalism and make it more uniform. Created in 2026, Pengauthor is actively curated by Editor-in-Chief Fun X Time. Through this powerful utility, CPA aims to make posts more structured and well-formatted.

**Registering slash commands:**
`npm run deploy` or run `./deploy-commands.js`

**Starting the bot:**
`npm run start`

**Testing the bot:**
`npm run dev`
